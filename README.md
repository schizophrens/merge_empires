## Features

- **6-player free for all** on a hex island, one Core each, last Core standing wins
- **Economy** built by placing farms, mines and oil rigs on resource tiles
- **Land and sea** combat with builders, soldiers, tanks and warships
- **Alliances** let two empires merge, but breaking one runs on a countdown so the betrayal is always visible
- **Concealment**, units hidden in tall grass disappear from enemy view
- **Terrain generated and rendered in Lua** with IMesh, no map brushes
- **Full menu and lobby** with parties, matchmaking, private matches with join codes, spectators, skins and progression
- **Blitz mode** runs the whole match at double speed
- In-game minimap, scoreboard, chat and interactive tutorial

## Installation

1. Download the ZIP from GitHub and extract it.
2. Move the extracted folder into `garrysmod/gamemodes/`.
3. Rename the folder to `merge_empires` (GitHub adds a `-main` suffix, remove it).

The final path must be `garrysmod/gamemodes/merge_empires/`.

Then start a server on the `merge_empires` map with the gamemode set to `merge_empires`.
